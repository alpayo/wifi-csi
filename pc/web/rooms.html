How the House map works✕

One card and one computer make a single radio link. A single link cannot locate a person — there is no geometry to triangulate with.

What it can do is recognise a learned fingerprint: someone moving in a given room disturbs a particular set of the radio's reflection paths, which shows up as a characteristic pattern across the 64 WiFi subcarriers. That pattern has to be taught before it can be recognised, so the map knows nothing about rooms until you walk each one (Calibrate).

After training it measures itself: each room is recorded twice, and accuracy is scored on the recording the model did not train on. Rooms the data can't tell apart are merged into one hatched zone, and rooms with low accuracy get a dashed outline — the map never shows them as a sure answer.

It reports where someone is moving. Someone sitting or lying still reads as "nobody moving"; the whole-home presence and breathing readings may still see them. With one card it names only the one strongest source of movement, not each room on its own, so a second person moving elsewhere won't show; more cards add more links. Closing or opening doors, moving furniture or moving the card changes the fingerprints — re-record the affected rooms and train again.

The hallway counts as part of the Entrance, and the balcony behind the glass as part of the Kitchen.
